# Bundled fonts

Latin subsets downloaded from Google Fonts and loaded with `next/font/local` in
`app/layout.tsx` and `app/admin/layout.tsx`, so builds don't fetch fonts from Google.

| File | Font | Weights |
| --- | --- | --- |
| `PressStart2P-Regular-latin.woff2` | Press Start 2P | 400 |
| `Fredoka-400-600-latin.woff2` | Fredoka (variable) | 400–600 |
| `RammettoOne-Regular-latin.woff2` | Rammetto One | 400 |
| `PlusJakartaSans-200-800-latin.woff2` | Plus Jakarta Sans (variable, admin only) | 200–800 |

All four are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which permits bundling them with the site.
